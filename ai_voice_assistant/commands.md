# Jarvis Commands Guide

This guide explains how to use your AI Desktop Assistant.

## 🚀 How to Start
1. Open your terminal.
2. Activate your environment: `source odoo-18-env/bin/activate`
3. Go to the project folder: `cd ai_voice_assistant`
4. Run the assistant: `python main.py`

## 🛑 How to Stop
You can stop Jarvis anytime using these methods:
- **Voice Command**: Say "Jarvis, stop" or "Jarvis, band karo".
- **Keyboard**: Press `Ctrl + C` in the terminal.

## 🗣️ Language Support
Jarvis now supports:
- **English**
- **Hindi (हिन्दी)**
- **Gujarati (ગુજરાતી)**

## 🎙️ Voice Commands

### 1. General Conversation
You can talk to Jarvis naturally in any of the supported languages.
- "Jarvis, how are you?"
- "Jarvis, tame kem cho?" (Gujarati)
- "Jarvis, aaj ka mausam kaisa hai?" (Hindi)

### 2. Opening Applications
- "Jarvis, open Chrome"
- "Jarvis, VS Code kholo"
- "Jarvis, Terminal chalao"

### 3. WhatsApp Messages
- "Jarvis, [Name] ko message bhejo [Your Message]"
- "Jarvis, [Name] ne message moklo [Your Message]"

### 4. System Control
- "Jarvis, shutdown system"
- "Jarvis, computer band karo"

### 5. Task Manager
- "Jarvis, remind me to buy milk at 5 PM"
- "Jarvis, mujhe yaad dilana kal meeting hai"
- "Jarvis, mari tasks batavo" (List tasks)

### 6. Google Calendar
- "Jarvis, what are my meetings today?"
- "Jarvis, aaj meri kya meetings hain?"
